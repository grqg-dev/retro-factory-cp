# NEXUS-9000 Factory Monitoring System

A retro-futuristic cyberpunk terminal application simulating a factory monitoring system.

![Cyberpunk Factory Monitor](https://i.imgur.com/placeholder.png)

## Features

- 🌐 Retro-futuristic cyberpunk interface
- 🔄 Real-time data visualization
- 🖥️ Terminal-based dashboard with multiple display widgets
- 🎭 Simulated factory system monitoring
- 🔥 Matrix-style boot sequence
- 🛡️ Random glitch events for immersive experience

## Requirements

- Node.js (version 14+)

## Installation

1. Clone this repository
2. Install dependencies:

```bash
npm install
```

## Usage

To run the application:

```bash
npm start
```

Or directly with Node:

```bash
node index.js
```

## Controls

- Press `q`, `Escape`, or `Ctrl+C` to exit the application
- Use arrow keys to navigate between panels (if interacting with tables)

## Technologies

- [blessed](https://github.com/chjj/blessed) - Terminal UI library
- [blessed-contrib](https://github.com/yaronn/blessed-contrib) - Dashboard widgets
- [chalk](https://github.com/chalk/chalk) - Terminal styling
- [figlet](https://github.com/patorjk/figlet.js) - ASCII art text
- [gradient-string](https://github.com/bokub/gradient-string) - Colorful gradients
- [ora](https://github.com/sindresorhus/ora) - Terminal spinners
